INSIDE JOKES - installable app (Android + iPhone)

1. PUT IT ONLINE (pick one, both free)
   Netlify Drop: unzip this folder, go to app.netlify.com/drop on a computer,
   drag the "inside-jokes-app" folder onto the page. Sign up so the site stays.
   GitHub Pages: make a public repo, upload these files (keep the icons folder),
   then Settings > Pages > Deploy from branch > main.

2. INSTALL ON ANDROID
   Open your link in Chrome > three-dot menu > "Install app" (or "Add to Home screen").

3. INSTALL ON IPHONE
   Open your link in Safari > Share button > "Add to Home Screen".

Files: index.html (the game), manifest.webmanifest (name + icon), sw.js (works offline), icons/.
Each phone keeps its own decks and photos. Use deck codes to share decks.
